# 拾页 FOLIO 产品需求文档

2026 年 11 月 21 日 · 比赛版需求与个人验收基线

## 产品定位

拾页面向想用英语外刊提升阅读与词汇能力的大学生。读者可以在读文章时就地查词，把选中的词义与文章中的出处一起保存，再通过认词和原文拼写复习。

发布形态为本地单用户 Web 应用。评委或队友可在自己的电脑上安装运行，各自拥有独立的 SQLite 学习记录。首次安装依赖需要联网，基础阅读与复习可离线使用，无服务订阅或模型 API Key 要求。启动步骤见 [README](../README.md#从零启动)。

## 已实现的比赛版范围

| 模块 | 功能 |
| --- | --- |
| 文章库 | 粘贴英文正文，或批量上传 UTF-8 TXT／Markdown、DOCX、PDF。扫描 PDF 使用本地英文 OCR。按明确标题、分隔线、PDF 顶层书签或常见英文试卷阅读分节尝试拆篇，保存前可勾选和编辑，试卷预览可查看整份提取文本。内置 3 篇原创样文和 7 篇媒体学习导读。支持搜索、组合筛选和删除文章。媒体导读提供对应原文链接。 |
| 阅读器 | 单栏阅读，字号、行距和段宽可调。记录读到的段落，重开文章可恢复位置。标题和正文均可点击、划选或用键盘选词。支持纯英文和中英双语显示，导入文章的译文可手动编辑。固定搭配首次出现时加下划线，收藏位置保留荧光标记。 |
| 词典与生词本 | 本地词典提供词形还原、多义项中英释义、音标及词表标签。读者可以一次收藏多个义项或自行填写释义，并保存标题或原句。支持按文章筛选、编辑备注、标记掌握度、删除和返回出处。 |
| 复习 | 每组默认 10 个到期词条，可设为 1–50。经典和翻卡模式都先显示词形，自评后展示释义和词性。「认识」后可点「继续」确认或点「记错了」重练。「模糊」「忘记」和「记错了」的词在下一小轮再次出现。经典模式整组认词完成后进入原句拼写，提交后展示结果和下次复习日期。 |
| 难度与打卡 | 正文按词频与句长估算四级、六级、雅思、GRE 四档，供选文参考。首次读完一篇文章或提交一次拼写复习时，记录当天活动，月历汇总完成的文章和复习次数。 |

媒体条目的站内正文是拾页编写的学习导读。实际报刊全文请经原文链接阅读，部分原文需要订阅。难度标注对应站内正文，属于项目估算，无法与官方考试分数换算。

首页采用近白背景、轻量卡片和本地实拍封面，图片缺失或加载失败时使用浅色栏目文字封面。来源和许可证见[设计规范](DESIGN.md#文章封面来源)。

试卷提取针对常见英文阅读结构。跨栏、低清、手写及特殊题型需要人工核对，少于 45 个英文词的候选不会自动列入。识别失败时保留整份文本。扫描识别需另外安装 Tesseract，步骤见 [README](../README.md#启用扫描-pdf-的英文-ocr)。

## 本次个人验收

推荐用一份单独的验收数据库，安装、启动方式见 [README](../README.md#从零启动)，数据库切换方式见 [架构文档](ARCHITECTURE.md#运行与数据存放)。这样当天打卡、到期队列和计数都有清楚的初始值。

| 步骤 | 操作 | 通过标准 |
| --- | --- | --- |
| 1. 启动与筛选 | 打开首页，按 The Guardian 和难度筛选，再清空筛选。 | 首页显示 10 篇内置材料。组合筛选和清空结果正确。打开导读后可看到出处和原文链接。 |
| 2. 导入与续读 | 粘贴或上传一篇有多个段落的英文文本，再调字号、行距和段宽。滚到后面的段落，等进度更新后刷新并重新打开。 | 标题和正文正确，排版调整生效，打开时能回到记录的段落。 |
| 3. 查词与收藏 | 打开 *What it means to hold rates steady*，在标题查 `steady`，在首段查 `held`，分别选择义项收藏。重复收藏同一个词义与同一出处。 | 标题和正文都能高亮并打开词卡。词卡能切换义项。生词本有两条词义，重复收藏不会增加同一出处。来源入口能回到标题或原段落。 |
| 4. 认词与重试 | 在复习设置中使用默认每组 10 词。两个词分别选「模糊」和「忘记」，看释义后继续。下一小轮把两词都选为「认识」。 | 先显示词，再显示释义。待重试词全部认出前没有拼写题，认词本身不计入打卡的复习次数。 |
| 5. 拼写与排期 | `steady` 正确作答，`held` 故意填成 `hold`。 | 按保存出处里的词形判分。新卡正确后安排两天后复习，答错安排次日。本组结果显示一词正确、一词重练。 |
| 6. 打卡与重启 | 回到样文底部点「完成阅读」，检查本月日历。重启服务，重新打开生词本、文章和打卡。 | 当天记录增加 1 篇已读和 2 次复习。重启后收藏、段落位置、复习日期与打卡仍可读取。 |
| 7. 扫描试卷导入 | 安装英文 OCR，上传包含两篇阅读文章的扫描试卷，勾选试卷模式，核对候选和整份文本，编辑标题后只勾选一篇导入。 | 常见结构能拆出阅读正文，题干和选项被排除。导入前不写入文章库，确认后仅保存勾选内容。特殊排版按原卷核对并记录问题。 |

验收时记录操作步骤、预期结果和实际结果。先修影响启动、数据保存或主流程的问题，再进入功能迭代。

## 后续范围与交付顺序

1. **本人先自验。** 按上表走完主流程，记录问题并复测。
2. **自验通过后完善功能。** 后续候选包括公共网页 URL 导入、AI 语境释义、长难句解析和 TTS。按自验反馈选优先级，保留离线基础流程。账号、云同步、多人协作和公网部署暂不列为比赛版范围。
3. **完善后由队友独立验收。** 队友在另一台电脑只按 README 安装、启动和复现流程，核对实际使用中的问题。
4. **准备参赛提交。** 按比赛日期在 12 月 6 日前提交完整代码仓库链接、演示视频、开发文档和成员参与度排名。
